## Requirements

- A running Meilisearch instance, v1.16 or later
- Its master key, or an API key with the `export` action
- A command-line terminal

You do not need a Meilisearch Cloud account. `meili teleport` creates one for you.

---

## Teleport with the CLI

### 1. Install the CLI

<Tabs>
<Tab title="npm">
```bash
npm install -g @meilisearch/cli
```

Installing with npm requires Node.js 22 or later.
</Tab>
<Tab title="Homebrew">
```bash
brew install meilisearch/tap/meili

# to upgrade
brew update && brew upgrade meilisearch/tap/meili
```
</Tab>
<Tab title="Install script">
```bash
curl -fsSL https://raw.githubusercontent.com/meilisearch/cli/main/scripts/install.sh | sh
```

The script works on macOS and Linux. Run it again to update the CLI.
</Tab>
</Tabs>

### 2. Run `meili teleport`

```bash
meili teleport
```

The command asks its questions in the terminal. It:

1. Asks for the instance to move, from your CLI config file or by its URL and API key
2. Checks that the API key can export data
3. Logs you in to Meilisearch Cloud in your browser, and creates your account if you do not have one
4. Creates the Cloud project: a free trial project if your account has not used its free trial yet, or a project on the plan you choose. Paid plans require a payment method in your Cloud account. See the [pricing page](https://www.meilisearch.com/pricing).
5. Adds the new project to your CLI config file
6. Sends your data to the new project and waits until it is indexed

### 3. Verify the migration

Open your [Cloud project](https://cloud.meilisearch.com) and run a few searches to confirm all data transferred correctly.

<Tip>
To migrate without questions, for example in a script, first run `meili auth login` yourself: it opens your browser to log in to Meilisearch Cloud. The script can then run `meili project add` and `meili export`. See the [CLI README](https://github.com/meilisearch/cli#readme).
</Tip>

## Export API

If you prefer not to use the CLI, the export API pushes your data directly from your self-hosted instance to a remote Meilisearch instance without creating any intermediate files.

### 1. Create a Meilisearch Cloud project

Navigate to [Meilisearch Cloud](https://cloud.meilisearch.com) and create a new project. Once it is ready, note down your project URL and API key from the project overview.

### 3. Verify the migration

Once the task status is `succeeded`, open your [Cloud project](https://cloud.meilisearch.com) and run a few searches to confirm all data transferred correctly.

</Warning>
