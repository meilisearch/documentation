These guides answer specific problems end to end. Each one runs from zero, with no prerequisites on other pages, so you can follow a single guide start to finish and have something working.

If you are looking for reference material on a single setting, see [Capabilities](/capabilities/overview). If you are looking for the HTTP API, see the [API reference](/reference/api/overview).

## Getting documents search-ready

Extracting, chunking, and indexing real-world content: PDFs, web pages, Office documents, and the systems that hold them.

## Diagnosing search quality and speed

Symptom-first troubleshooting. Start here when something is already broken.

## Hard search problems

Multi-tenancy, multilingual search, personalization, and the problems where a naive implementation works until it does not.

## Choosing an approach

Decisions framed by your constraints: document count, latency budget, cost ceiling, and which model to use.

## Agentic and MCP retrieval

Building retrieval that an AI agent can use, including MCP servers, tool calling, and RAG pipelines that cite their sources.

## Problem explainers

Why common search problems happen, what causes them architecturally, and how to fix them.
