The Meilisearch JavaScript SDK lets you use Meilisearch from Node.js and browser applications. It wraps every route of the HTTP API in a typed method.

## Installation

Install the package with your preferred package manager. The SDK has no runtime dependencies.

## Usage

Create a client with your instance URL and API key, then call `index().search()` to query an index. Every method returns a promise.
