---
title: Authentication
description: Authenticate your Management API requests with a personal access token.
---

The Management API lets you manage your Meilisearch Cloud resources programmatically. It is served at `https://api.meilisearch.com`.

All requests must be authenticated with a personal access token (PAT). You can generate one in the account settings of the [Meilisearch Cloud dashboard](https://cloud.meilisearch.com).

<Warning>
  A personal access token grants access to your Meilisearch Cloud account. Keep it secret and never expose it in client-side code.
</Warning>
